# Lëtzebuergesch

Portail de révision du luxembourgeois, publié sur GitHub Pages.

- La page appelle le projet Apps Script (URL `/exec` dans `index.html`). Aucun code d'accès n'est dans ce dépôt : il est saisi une fois sur l'appareil (ou ouvert depuis un lien personnel `#k=…`, aussitôt effacé de l'adresse).
- Hors ligne : `sw.js` garde la page, les icônes et les polices ; la page garde la dernière copie des données et met les envois en file jusqu'au retour du réseau.
